# 테이블 관리 유스케이스

> 이 문서는 구현 코드 기준의 실제 유스케이스 명세입니다.
> 도메인 규칙 변경 시 반드시 함께 수정하세요.

---

### 테이블 생성

- **점주는 가게의 테이블을 생성할 수 있다**
    - 테이블 번호, 테이블 위치(2차원 좌표 x, y), 테이블 수용 인원의 정보로 생성할 수 있다.
    - 테이블 번호는 같은 가게 내에서 고유해야 한다.
    - 테이블 생성은 가게가 마감 상태(활성 영업 없음)이어야 한다.
    - 본인 가게에만 테이블을 생성할 수 있다.

---

### 테이블 수정

- **점주는 가게의 테이블을 수정할 수 있다**
    - 테이블 번호, 테이블 위치(2차원 좌표 x, y), 테이블 수용 인원을 수정할 수 있다.
    - 테이블 수정은 가게가 마감 상태이어야 한다.
    - 본인 가게의 테이블만 수정할 수 있다.

---

### 테이블 삭제

- **점주는 가게의 테이블을 삭제할 수 있다**
    - 테이블 삭제는 가게가 마감 상태이어야 한다.
    - 본인 가게의 테이블만 삭제할 수 있다.

---

### 테이블 조회

- **누구나 가게의 테이블 목록을 조회할 수 있다**
    - `storeId`로 해당 가게의 전체 테이블 목록을 조회할 수 있다.
    - 인증 없이도 조회할 수 있다(익명 포함).

---

### 테이블 활성화 상태

- **고객이 QR 코드로 테이블에 접근하면 테이블이 활성화된다**
    - 영수증 발급 시 해당 테이블의 활성화 상태가 `true`로 변경된다.
- **영수증이 정산되거나 삭제되면 테이블이 비활성화된다**
    - 정산 완료 또는 영수증 삭제 시 해당 테이블의 활성화 상태가 `false`로 변경된다.
- **점주는 영수증을 다른 테이블로 이동할 수 있다**
    - 이전 테이블은 비활성화되고, 새 테이블은 활성화된다.
