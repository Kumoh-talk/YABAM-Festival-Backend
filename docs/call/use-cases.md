# 직원 호출 유스케이스

> 이 문서는 구현 코드 기준의 실제 유스케이스 명세입니다.
> 도메인 규칙 변경 시 반드시 함께 수정하세요.

---

### 호출 생성

- **고객은 직원 호출을 할 수 있다**
    - 영수증 ID와 호출 메시지로 직원을 호출할 수 있다.
    - 점유 중인 활성화된 테이블에 연결된 미정산 영수증이 있어야 호출할 수 있다.
    - 인증 없이도 가능하다.

---

### 호출 완료 처리

- **점주는 직원 호출을 완료 처리할 수 있다**
    - `callId`로 특정 호출을 완료 상태로 변경할 수 있다.
    - 본인 가게의 호출만 완료 처리할 수 있다.
    - 점주(`ROLE_OWNER`) 권한이 필요하다.

---

### 호출 조회

- **점주는 완료되지 않은 직원 호출 목록을 조회할 수 있다**
    - `saleId`로 해당 영업의 미완료 호출 목록을 커서 기반 페이지네이션(`lastCallId`, `size`)으로 조회할 수 있다.
    - 본인 가게의 영업에 대해서만 조회할 수 있다.
    - 점주(`ROLE_OWNER`) 권한이 필요하다.
