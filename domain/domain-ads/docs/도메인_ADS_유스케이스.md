## 광고 ADS 유스케이스

### 개요

- 기존 축제 주막 View 페이지
    - 기존 축제 주막 View 페이지는 축제에 가게들에 대한 랜덤 정렬로 노출이 되고 있습니다.
    - 사이 사이 광고를 적용하여 광고 수익을 창출하고자 합니다.

### 아이디어

- 광고 적용 위치
    - 기본 축제 주막 View 페이지에 특정 번수에 삽입
- 광고 노출 방식
    - 거리, 이용 주문 수, 등등의 조건으로 정렬된 광고 삽입
- 금액 정책
    - 페이지 노출, 클릭, 전환 등 다양한 방식으로 금액 정책 설정
        - 해당 방법을 적용할 시 브루트 포스 공격에 방어에 유의해야 할듯 (ex. 동일 IP에서 반복 클릭 제한 등으로 방어 고려)
- 광고 상품
    - 가게 기준 노출 위치별 상품
