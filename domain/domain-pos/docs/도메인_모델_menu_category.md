## Domain Model (MenuCategory)

### MenuCategory

_Aggregate Root_

#### 속성

- `id`: 카테고리의 고유 식별자
- `name`: 카테고리 이름
- `order`: 카테고리 순서
- `storeId`:`Long` : 가게 고유 ID

#### 행위

- create() : 카테고리 생성
- updateName() : 카테고리 이름 수정
- updateOrder() : 카테고리 순서 수정

#### 제약

- create 연산에는 카테고리 이름, 순서는 필수값이다.
    - 가게 소유자만 가능하다.
    - 영업전에만 가능하다.
    - 필수값인 순서는 사용자에게 입력받는 것이 아닌, 현재 존재하는 카테고리 순서 최댓값 + 1로 설정해야한다.
- updateName 연산에는 카테고리 이름만 변경 가능하다.
    - 가게 소유자만 가능하다.
    - 영업전에만 가능하다.
- updateOrder 연산에는 카테고리 순서만 변경 가능하다.
    - 가게 소유자만 가능하다.
    - 영업전에만 가능하다.
    - 범위 내의 다른 카테고리들의 순서 재배치가 이루어져야한다.
