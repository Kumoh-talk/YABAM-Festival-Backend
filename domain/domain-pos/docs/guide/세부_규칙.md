## 1. 도메인 모델 생성일, 수정일, 삭제일 관리

- 일자 정보를 관리하고 싶은 도메인 모델은 common 모듈의 AuditStamp 클래스를 상태에 포함한다.
    - AuditStamp 클래스는 생성일(createdAt), 수정일(updatedAt), 삭제일(deletedAt)을 속성으로 가진다.
- AuditStamp는 읽기 전용 VO로, 도메인 계층에서 값을 생성하지 않고, 인프라 계층에서 JPA에 의해 기록된 값을 사용한다.
    - 도메인 모델을 최초 create 할 때는 AuditStamp를 생성하지 않고, JPA 엔티티를 도메인 모델로 매핑하는 과정에서 AuditStamp를 생성한다.
        - ```java
          public static Menu fromInfra(Long id,
          MenuInfoState menuInfoState,
          Integer order, boolean isSoldOut, boolean isRecommended,
          AuditStamp auditStamp, Long storeId, Long menuCategoryId) {
            return Menu.builder()
                .id(id)
                .menuInfo(MenuInfo.of(menuInfoState))
                .order(order)
                .isSoldOut(isSoldOut)
                .isRecommended(isRecommended)
                .auditStamp(auditStamp)
                .storeId(storeId)
                .menuCategoryId(menuCategoryId)
                .build();
          }
          ```
    - 매핑 과정에서 AuditStamp을 생성할 때, 경우에 맞게 AuditStamp 내부 정적 메소드를 호출하여 AuditStamp를 생성한다.
        - 최초 생성 시 AuditStamp.create(), 수정 시 AuditStamp.update(), 삭제 시 AuditStamp.delete()를 호출한다.
        - AuditStamp 정적 메소드는 인프라에서만 호출하도록 한다. -> 추후 테스트 코드 작성 필요
